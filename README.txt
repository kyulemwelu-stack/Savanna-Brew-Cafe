SAVANNA BREW CAFÉ WEBSITE
HTML & CSS Assignment

PROJECT DESCRIPTION

Savanna Brew Café is a responsive five-page website developed using HTML5 and CSS3.

The website includes Home, About, Menu, Gallery, and Contact & Reservations pages.

TECHNOLOGIES USED

HTML5
CSS3
CSS Grid
Flexbox
Responsive Media Queries
Google Fonts

HOW TO RUN THE WEBSITE

1. Extract the project ZIP folder.
2. Open the extracted folder.
3. Double-click index.html to open the homepage.
4. Navigate through the five pages using the navigation menu.
